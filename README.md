# Costeo de Recetas

Calculadora de costos de recetas con biblioteca de recetas y precios de referencia para Tijuana, B.C. Funciona sin internet una vez instalada.

App: https://valenzuelajesuspsico-ui.github.io/costeo-recetas/

- `index.html`: la aplicación completa (un solo archivo).
- `sw.js`, `manifest.json`, `icon-*.png`: hacen que se pueda instalar como app en el teléfono.
- Los precios se actualizan cada lunes de forma automática.
